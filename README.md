# 문제은행 수행평가

학생마다 다른 20문항을 단원별 균등 규칙으로 뽑아 출제하는 수행평가 사이트입니다.

- `index.html` — 학생 응시·결과 확인
- `admin.html` — 교사 관리(수업 운영·결과·문제은행·학생 코드·설정)
- `supabase/` — 데이터베이스 구조와 출제·채점 함수(Supabase)
- `tools/parse_questions.py` — 문항 파일 확인용 파서

문항·정답·학생 코드·점수는 저장소가 아니라 Supabase에 있으며 교사 계정만 볼 수 있습니다.
`config.js`에는 브라우저에 공개해도 되는 접속 키(anon)만 들어 있습니다.
